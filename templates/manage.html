Новое соревнование

Подходит файл, выгруженный кнопкой «Экспорт БД» (или любая база «Хронометража»). Создаётся новое соревнование с отдельной копией базы — загруженный файл не меняется.

Доступ к управлению

Сейчас вход под логином {{ manage_user }}. Логин и пароль этой страницы хранятся в файле данных (пароль — в виде хэша). Пока файл не создан, действуют значения из переменных окружения сервера.
Пустое поле не меняется. Чтобы вернуться к учётке из переменных окружения, удалите файл manage.json в каталоге данных.
