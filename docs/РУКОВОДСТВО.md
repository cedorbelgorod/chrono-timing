# Хронометраж — руководство по работе

Версия документа: 21.11.2026
Сайт: **https://hrono.cedor.ru**

---

## 1. Что это и как устроено

Веб-приложение для хронометража велогонок: регистрация участников, старты, отсечки кругов и финиша,
результаты и печать протокола. Работает с телефона, планшета и компьютера — интерфейс подстраивается
под экран.

Главный принцип: **одно соревнование — одна база данных**. В системе может быть сколько угодно
соревнований, у каждого свои участники, категории, старты и свои логины/пароли. Данные одного
соревнования не видны и недоступны в другом.

Три способа попасть на нужное соревнование:

- выбрать его на главной странице — `/`;
- открыть прямую ссылку `/c/<код>` (например `/c/velokros-2-etap`);
- выбрать в списке на странице управления `/manage`.

---

## 2. Быстрый старт: что делать в день гонки

1. **До гонки** — завести категории (круги, пол, годы рождения), проверить данные для протокола.
2. **До гонки** — собрать заявки: вручную, импортом из Excel или через публичную форму саморегистрации.
3. **На старте** — создать старт: выбрать категории, участников, параметры, нажать «Создать и начать».
4. **На дистанции** — работать на странице «Хронометраж»: вводить номер и отмечать круги/финиш.
5. **После финиша** — проверить результаты на странице «Результаты», при необходимости поправить время.
6. **Итог** — распечатать протокол (PDF) и/или выгрузить результаты.

## 3. Доступ, вход и роли

### Вход

1. Откройте сайт — появится список соревнований.
2. Нажмите «Войти» у нужного соревнования.
3. Введите логин и пароль **этого соревнования**.

Каждое соревнование имеет свои учётные записи: судья «Велокроса» не сможет войти в «Домашнюю гонку»,
даже зная адрес.

### Роли

| Роль | Что может |
|---|---|
| **Администратор** | Всё: соревнование, категории, участники, старты, хронометраж, результаты, протокол, пользователи |
| **Судья** | Всё, кроме управления пользователями |
| **Хронометрист** | Только страница «Хронометраж» — ввод номеров и отметки |

Пользователей заводит администратор: «Соревнование» → «Пользователи» (`/users`).

### Смена соревнования

Кнопка **⇄** в шапке рядом с названием — возвращает к списку соревнований. Один браузер может
держать вход сразу в несколько соревнований: пароль повторно вводить не нужно.

## 4. Выбор соревнования

Главная страница (`/`) показывает список всех соревнований: название, пометка «только чтение»,
кнопка «Открыть» или «Войти».

Прямая ссылка на соревнование — `/c/<код>`, например:

- `https://hrono.cedor.ru/c/velokros-2-etap`
- `https://hrono.cedor.ru/c/domashnyaya-gonka`

После входа можно сразу открыть нужную страницу: `/c/<код>?next=/manual` (хронометраж),
`?next=/races` (старты), `?next=/dashboard` («Что сейчас идёт»).

## 5. Настройка соревнования

Раздел **«Соревнование» → «Настройки»** (`/competitions`).

- **Название** — отображается в шапке, протоколе и публичных страницах.
- **Формат стартов** — «Групповой старт» или «Раздельный старт». Задаётся **при создании
  соревнования** (страница «Управление соревнованиями») и потом не меняется; на странице
  настроек показывается только для сведения. Для разделки здесь же настраивается интервал
  старта и звуковой отсчёт.
- **Дата старта** — плановая дата соревнования. Показывается в форме регистрации и в списке
  зарегистрировавшихся. **Год этой даты** используется для расчёта возраста в категориях.
  При смене года и наличии участников приложение спросит, пересчитать ли категории.
- **Данные для протокола**:
  - заголовок протокола (несколько строк),
  - место проведения,
  - главный судья, судья на старте, судья на финише, главный секретарь,
  - название трассы и её регистрационный номер,
  - погода: город (или широта/долгота), состояние и температура в начале и в конце, влажность.
    Кнопка «🌤 Узнать погоду» подтягивает данные автоматически.
- **Что уже заведено** — счётчики категорий, участников, стартов.

На этой же странице есть переходы к категориям, участникам и странице управления соревнованиями.

## 6. Категории

Раздел **«Соревнование» → «Категории»** (`/competitions/<id>/categories`).

Таблица компактная — в строке только **порядок**, **название** и **кругов**:

- **⋮⋮** — перетащите строку, чтобы изменить порядок групп. Значения пересчитываются 1…N
  и **порядок сохраняется сразу** (рядом появляется «Порядок сохранён»).
  Если вписать число в поле вручную — понадобится «💾 Сохранить все изменения».
- **− 1 +** — быстро изменить число кругов.
- **⚙** — условия категории (пол, возраст, круг, HD/МС/ТС) открываются в окошке,
  синяя шестерёнка — значит условия заданы. Изменения в окошке применяются кнопкой
  «Сохранить все изменения» внизу страницы.
- **🗑** — удалить категорию (с подтверждением).

У категории есть:

| Поле | Смысл |
|---|---|
| ID | Номер записи в базе — **не меняется** |
| Сортировка | Порядок групп на старте «по группе, затем номер». По умолчанию равна ID, можно менять. Таблица категорий отсортирована по этому полю |
| Название | Как в протоколе, например «Мальчики 8 лет и младше» |
| Кругов | Сколько кругов едет категория |
| Пол | Галочки «М» / «Ж». Пусто — подходит обоим |
| Возраст | Возраст участника строкой: `9-10`, `-6` (6 лет и младше), `9-` (9 лет и старше), `9` (ровно 9). Пусто — без ограничения |
| Круг, км / HD / МС / ТС | Данные трассы для протокола |

### Возраст и годы рождения

Возраст участника считается **на 31 декабря года старта**: `возраст = год старта − год рождения`.
Поэтому у категории рядом с возрастом показывается подсказка, какие годы рождения в неё попадают
(например, «2016–2017 г.р.»). При смене даты старта подсказка и условия пересчитываются.

### Автоподбор категории

Если у категории заданы пол и/или возраст, участнику **автоматически назначается первая
подходящая** категория (по порядку создания) при:

- саморегистрации,
- импорте из Excel (если категория не указана в файле или не найдена),
- ручном добавлении участника без выбора категории.

Если ни одна категория не подходит — участник остаётся без категории, её назначают вручную.

### Пересечения

Если условия двух категорий пересекаются (например по возрасту), обе **подсвечиваются красным**
с подписью «⚠ условия пересекаются». Это предупреждение, а не запрет: сохранять можно.

### Ошибки при сохранении

Если что-то заполнено неверно (пустое название, кругов меньше 1, возраст «от» больше возраста «до»,
такая категория уже есть) — страница не перезагружается: введённые данные остаются,
проблемное поле подсвечивается красным с пояснением.

### Импорт из Excel

На странице категорий — блок **«Массово»**:

1. **«⬇ Шаблон»** — скачать файл с колонками: Название · Кругов · Пол · Возраст
   (в шаблоне есть примеры строк: `18-`, `-8`, `12-14`).
2. Заполнить и нажать **«📥 Импорт из Excel»** — файл проверяется и показывается предпросмотр:
   какие категории новые, какие уже есть, где ошибка, какие годы рождения получатся.
3. Нажать **«Импортировать N категорий»** — добавляются только новые строки.

Пол: `М`/`Мужской`/`M`, `Ж`/`Женский`/`F`; пусто — категория без ограничения по полу.
Возраст можно не заполнять. Колонка «Название» обязательна. Старые файлы с колонками
«Год с»/«Год по» тоже читаются — годы переводятся в возраст по году старта.

## 7. Участники

Раздел **«Соревнование» → «Участники»** (`/competitions/<id>`).

### ID и стартовый номер

- **ID** — постоянный идентификатор участника. Присваивается автоматически при саморегистрации,
  импорте и ручном добавлении, есть всегда и не меняется.
- **Номер** — стартовый номер. Выдаётся на старте, когда участник подошёл к судье.
  Может отсутствовать; в пределах соревнования уникален.
- В работе (хронометраж, результаты, протокол) используется **номер**.

### Выдача номеров на старте

Страница **«Соревнование» → «🔢 Выдать номера»** (`/competitions/<id>/numbers`):

1. Найдите участника по ФИО, ID или номеру (или пролистайте список — сверху видно, сколько человек
   ещё без номера).
2. Впишите номер и нажмите «Выдать». Номер сразу появится у участника и станет доступен в стартах.
3. Занятый номер выдать нельзя — система подскажет, за кем он закреплён.

Без номера участник **не попадает в старт**: на странице «Старт» висит предупреждение
«Без стартового номера: N» со ссылкой на выдачу.

### Метки на номерах

RFID-метка принадлежит **номеру**, а не участнику: она клеится на стартовый номер.
Участник получает метки вместе с номером — в списке участников они показываются только для чтения.

Страница **«Соревнование» → «📡 Метки»** (`/competitions/<id>/tags`):

- привязать к номеру **две метки** — основную и резервную (вторая необязательна);
- метки можно наклеить **заранее**, даже если номер ещё не выдан участнику;
- одна и та же метка не может быть на двух номерах;
- при сохранении прежние метки номера заменяются; пустые поля снимают метки;
- список показывает, у каких номеров меток ещё нет (в автохронометраже участвуют только
  помеченные номера).

Номер вместе с метками передаётся другому участнику автоматически — достаточно переназначить номер.

**Импорт меток из Excel** — блок «Массово» на странице «Метки»:

1. **«⬇ Шаблон»** — файл с колонками **Номер · Метка 1 · Метка 2** (есть примеры строк).
2. **«📥 Импорт из Excel»** — файл проверяется, показывается предпросмотр: у каких номеров метки
   новые, у каких будут заменены, где ошибки (неверный номер, метка уже на другом номере,
   метка дважды в строке).
3. **«Импортировать N номеров»** — метки сохраняются; для номеров из файла прежние метки заменяются.

### Добавление вручную

Кнопка «＋ Добавить участника» открывает панель: ФИО, год рождения, пол, категория, город, клуб.
Номер можно не указывать — тогда участник будет без номера (номер выдаётся на старте).

При вводе первых букв ФИО появляются подсказки из **общего списка ранее регистрировавшихся**:
выбор подставляет ФИО, год рождения, город, клуб и пол.

### Импорт из Excel

Кнопка «📥 Импорт из Excel» (`/competitions/<id>/participants/import`).

1. Скачайте шаблон кнопкой «⬇ Шаблон».
2. Заполните и загрузите файл — откроется предпросмотр с проверкой строк.
3. Проверьте, при необходимости включите «создавать отсутствующие категории»,
   нажмите «Импортировать».

Поддерживается формат выгрузки Google Forms — колонки распознаются автоматически:
«Отметка времени», «Фамилия Имя», «Год рождения», «Пол», «Населенный пункт», «Команда», телефон.
Категория (группа) может отсутствовать — тогда она подберётся по условиям или останется пустой.

### Массовые операции

Отметьте участников галочками — появится панель действий:

- **Назначить группу** (категорию),
- проставить город,
- проставить команду,
- удалить выбранных.

### Поиск, фильтры, сортировка

- Поиск по ФИО — поле над таблицей (фильтрует по мере ввода).
- Фильтры: категория (включая «Без группы»), город, команда, пол,
  год рождения: равно / больше / меньше / между.
- Сортировка — нажатие на заголовок столбца (повторное нажатие меняет направление).

### Подсветка «не по возрасту»

Если участник не попадает в условия своей категории (возраст или пол), строка подсвечивается
**жёлтым** и в столбце «Категория» появляется пометка «⚠ не по возрасту». Это не ошибка и не
запрет — просто подсказка, что категорию стоит пересмотреть (или что участника нужно перевести).

### Правка и удаление

В строке участника — редактирование полей и удаление. Изменения пачкой сохраняются кнопкой внизу.

## 8. Саморегистрация участников

Раздел **«Соревнование» → «📝 Саморегистрация»** (`/registration`).

### Настройка

1. Поставьте галочку **«Разрешить публичную регистрацию»**.
2. Заполните **информацию о соревновании** — её участник увидит первой (дата, место, программа, взносы).
3. Укажите **дату окончания регистрации** (пусто — без ограничения; дата действует до 23:59).
4. Отметьте **поля формы**: ФИО (всегда), Пол, Город, Клуб, Год рождения, Категория, Телефон.
   Для каждого поля — «Показывать» и «Обязательное».
5. При необходимости отредактируйте **текст согласия** на обработку персональных данных.
6. Нажмите «Сохранить настройки».

После сохранения появится **ссылка для участников** (`/reg/<код>`) с кнопкой «Копировать» и QR-кодом.

### Что видит участник

1. Страница с названием соревнования, сроком, информацией и кнопкой «Согласен(на) с условиями».
2. **Мастер по шагам** — по одному полю на странице: ФИО → Пол → Год рождения → Город → Клуб →
   Категория → Телефон. Сверху «Шаг N из M» и полоса прогресса, снизу «Назад» и «Далее».
   Введённое сохраняется, можно вернуться и исправить.
3. Категории показываются только подходящие по полу и году; если подходящих нет — сообщение,
   что категорию назначит организатор.
4. Последний шаг — «Проверьте данные»: сводка и галочка согласия 152-ФЗ.
   Кнопка «Отправить заявку» становится активной только после галочки.
5. После отправки — экран «Заявка отправлена» с **ID участника** (стартовый номер выдадут на старте),
   кнопки «Зарегистрировать ещё участника» и «Список участников».

### Автоподстановка

На шаге ФИО достаточно ввести первые буквы — появятся подсказки из общего списка
ранее регистрировавшихся (когда вариантов меньше пяти). Выбор заполняет ФИО, пол, год, город и клуб,
и мастер переходит сразу к первому пустому шагу.

### Журнал заявок

Каждая заявка сохраняется в отдельном журнале и **не удаляется вместе с участником**:
если участника удалили из списка, заявка остаётся — со всеми введёнными данными и отметкой «удалён».

Раздел **«Соревнование» → «📋 Журнал заявок»** (`/registrations`):

- дата и время подачи, ФИО, год рождения, пол, город, клуб, телефон, категория;
- статус: «в списке» (с номером, если выдан) или «удалён»;
- **техническая информация**: IP-адрес, браузер, операционная система, тип устройства
  (телефон/планшет/компьютер), язык, источник перехода, полная строка User-Agent;
- кнопка **«⬇ Excel»** — выгрузка журнала (`/registrations.xlsx`).

На странице «Саморегистрация» показываются последние заявки и ссылка на полный журнал.

### Публичный список участников
Ссылка `/reg/<код>/list` — список зарегистрированных: №, ФИО, год, город, клуб, категория.
**Телефоны не публикуются.** На странице есть кнопка **«📥 Excel»** (`/reg/<код>/list.xlsx`).

### Ограничения и защита

- Регистрация закрывается по дате окончания или снятием галочки.
- В режиме «только чтение» регистрация недоступна.
- Повторная заявка с тем же ФИО и годом рождения не создаётся — придёт сообщение с номером.
- Не больше 5 отправок с одного адреса за 5 минут.
- Поле «Пол» нужно включить, если в категориях есть ограничение по полу — иначе категория не подберётся
  (страница настроек предупредит об этом).
- Кнопка **«🎯 Подобрать категории»** на странице настроек назначает категории тем, кто уже
  зарегистрировался без неё.

## 9. Старты

Раздел **«Старт»** (`/races`).

### Тип стартов у соревнования

Все старты соревнования одного типа. Тип выбирается **при создании соревнования**
(«Управление соревнованиями» → «Новое соревнование» → «Тип старта») и в уже созданном
соревновании не меняется; на странице «Соревнование» он показан только для сведения.

- **Групповой старт** (`mass`, по умолчанию) — все едут вместе, считаются круги;
- **Раздельный старт** (`itt`) — участники стартуют по одному с интервалом; результат — личное время.

Тип соревнования виден бейджем на главной странице: «Разделка» или «Массовый».
Для разделки на странице «Соревнование» задаётся **интервал старта** (по умолчанию 30 с,
от 5 до 600) и **звуковой отсчёт** на табло. Уже созданные старты сохраняют свой тип.

### Создание старта

1. Выберите категории (в списке только те, где есть свободные участники **с выданным номером**).
2. Отметьте участников (или «выбрать всех» в категории).
3. Параметры:
   - **Финиш после лидера** — когда лидер финиширует, остальные закрываются на следующей отсечке
     (только для группового старта);
   - **Авто (RFID)** — учитывать отметки считывателя;
   - **Мин. время круга** — защита от двойных срабатываний;
   - **Порядок старта** — для разделки: «по номеру» или «по группе, затем номер»
     (сначала группы по колонке **«Сортировка»** категории, внутри — по номерам). Выбор запоминается
     как значение по умолчанию для следующих стартов.
4. «Создать» или «Создать и начать».

### Раздельный старт: как проходит

1. Созданный старт запускается как обычно («Создать и начать») — либо прямо с табло кнопкой
   **«▶ Начать старт»**. Пока старт не запущен, табло показывает очередь в режиме предпросмотра:
   можно **переставить порядок** стрелками ↑ ↓ и только затем запустить.
2. **Стартовый судья** открывает **«Хронометраж» → «Табло старта»** (`/manual?mode=start`):
   часы, «Стартует: №…», обратный отсчёт до планового старта, очередь, кнопки
   **СТАРТ / Пропустить (DNS) / ↶**, лента последних стартов, звук 5-4-3-2-1.
   Нажатие СТАРТ фиксирует фактическое время старта; следующее плановое = это время + интервал.
   Опоздавшего отмечают «Пропустить» (получает DNS и не едет).
3. **Порядок старта** задаётся параметром старта: **по номеру** или **по группе, затем номер**.
   Его видно на табло («Дальше в очереди · по группе, затем номер»), а участники идут
   с подписью своей группы. Порядок можно менять вручную: стрелки ↑ ↓ у каждого участника
   в очереди — это перекрывает выбранную сортировку. Работает и до запуска старта, и во время —
   для тех, кто ещё не стартовал (переставить уже стартовавшего нельзя). Порядок сохраняется в базе.
   Кнопка **«↶ Отменить старт»** спрашивает подтверждение и показывает, кого именно отменит
   («Отменить старт №12 (ФИО)?») — от случайного нажатия не сработает.
4. **Финишный судья** работает на обычной странице «Хронометраж»: вводит номер (или срабатывает
   метка) и нажимает «ФИНИШ». У едущих видно «в пути: мм:сс».
5. Старт закрывается сам, когда все стартовавшие финишировали (DNS не мешают).

### Круги в разделке

Разделка может идти по кольцевой трассе, и **число кругов задаётся категорией**:
у каждой категории своё значение «Кругов». Участник всегда проезжает все свои круги;
«финиша после лидера» в разделке нет.

- На «Хронометраже» у едущего видно **«Круги: X / N · в пути: мм:сс»**; кнопка
  называется **«КРУГ»** до последнего круга и **«ФИНИШ»** — на последнем.
- На табло старта у «Стартует: №…» показывается **«Круги: N»**.
- Автохронометраж: каждая метка — круг, на последнем — финиш.
- В результатах для разделки есть колонки **«Круги»** (`X / N`) и **«Место (сейчас)»** —
  промежуточное место по текущему времени внутри категории (финишировавшие — по итоговому
  времени, едущие — по «в пути»). Итоговое «Место» заполняется после финиша.
- В стартовом и итоговом протоколах (PDF и Excel) есть колонка **«Круги»**.

Результат в разделке — **время от старта до финиша**; места — по возрастанию времени
**внутри категории**, отставание — от победителя категории. В результатах, протоколе (и PDF)
для разделки добавляются колонки **«Старт» и «Финиш»**.

### Порядок участников и стартовый протокол

В карточке старта на странице «Старты» для разделки показывается список участников
в порядке старта — позиция, номер, ФИО, группа, время старта и статус.

- **Перетаскивание за ⋮⋮** меняет порядок, сохранение происходит сразу
  (рядом появляется «Порядок сохранён»). Пока старт не запущен, переставлять можно всех;
  после запуска — только тех, кто ещё не стартовал, а строки стартовавших закреплены сверху
  с фактическим временем.
- **«↺ По номеру» / «↺ По группе»** — сброс ручного порядка к автоматическому.
- **«Старт в»** — плановое время первого участника (дата и время). От него считается
  время каждого следующего: `Старт в + (позиция − 1) × интервал`. Если не задано — в протоколе «—».
- **«📋 Протокол старта»** открывает стартовый протокол: таблица «№ п/п · номер · ФИО · год ·
  группа · город · команда · время старта · примечание», подписи главного судьи и секретаря.
  Доступны **PDF**, **Excel** и печать. Пока старт идёт, у стартовавших показывается фактическое
  время, у остальных — плановое, у DNS — пометка.
- **«🔗 Публичная ссылка»** создаёт адрес вида `https://<домен>/sl/<токен>` — протокол
  открывается без входа, обновляется сам и читается с телефона. Ссылку можно перегенерировать.

### Идущий старт

Карточка старта показывает заезды по категориям: номер, ФИО, круги, время, отставание.
Доступны:

- переименование старта,
- запуск (`Начать`),
- правка времени финиша,
- удаление круга,
- отметка DNF (не финишировал),
- принудительное завершение старта.

Список стартов обновляется автоматически каждые 4 секунды.

### Завершение

Старт закрывается сам, когда все заезды завершены. Если кто-то не финишировал — отметьте DNF
или завершите старт принудительно: отставшие получат статус «отстал на N кругов».

## 10. Хронометраж

### Ручной (страница «Хронометраж», `/manual`)

1. Судья видит участника заранее и **вводит его номер** в поле сверху.
2. Список «На дистанции» фильтруется по введённому номеру, совпавший выделяется.
3. Когда участник пересекает линию — кнопка **«КРУГ N»** или **«ФИНИШ»** (или клавиша Enter в поле номера).
4. После финиша показывается всплывающее «ФИНИШ!» — оно закрывается само или при начале ввода.
5. Ошибку можно отменить кнопкой **«↶»** (последнее действие).
6. Список обновляется каждые 2 секунды; внизу — журнал отметок.

Подсказки: поле номера сохраняет фокус, ввод номера фильтрует список, прогресс участника виден
в строке («Круги: 1 / 3») и в кнопке («КРУГ 2» / «ФИНИШ»).

### Автохронометраж (RFID, `/auto`)

Страница для считывателя: подключение устройства, выбор порта, включение авто-режима,
журнал срабатываний, сравнение ручных и автоматических отметок, экспорт.

Как работает с метками:

- метка наклеена на **номер** (см. «📡 Метки»), участник определяется по номеру;
- на номере может быть две метки — основная и резервная; **отметка идёт по первой считанной**;
- если вторая метка номера считается почти сразу, второй круг **не** засчитывается: срабатывает
  защита «Мин. время круга» (настройка старта, по умолчанию 5 с) — в журнале будет «Рано»;
- метка, не привязанная ни к одному номеру, в журнале отмечается как «Метка не привязана к номеру»;
- метка номера, который ещё не выдан участнику, тоже не даёт отметки.

## 11. Результаты, протокол, итоги

| Страница | Что показывает |
|---|---|
| **Что сейчас идёт** (`/dashboard`) | Идущие старты в реальном времени: круги, отставания, лидеры |
| **Результаты** (`/results`) | Результаты по стартам и категориям, отставания, экспорт |
| **Итоги** (`/summary`) | Сводка по соревнованию: участники, старты, заезды, отметки |
| **Протокол** (`/protocol`) | Печатный протокол; PDF — кнопкой «Скачать PDF» (`/protocol.pdf`) |
| **Экран финиша** (`/finish-screen`) | Публичный экран для проектора: кто финишировал |
| **Журнал** (`/logs`) | Все действия хронометража с логинами и временем |

Протокол PDF формируется по категориям: у каждой категории своя страница, шапка с составом ГСК
и техническими данными трассы, внизу — погодные условия, статистика и подписи.

### Публичные страницы

На главной странице у каждого соревнования две кнопки: **«Войти»** — для судей,
и **«🌐 Публичная страница»** — для участников и зрителей (открывается без входа).

**Публичная страница (хаб)** — `/p/<slug>`:

- название и дата соревнования;
- кнопки «Зарегистрироваться» (если саморегистрация включена), «Результаты», «Табло»;
- **все старты** соревнования с числом участников, статусом и ссылкой на стартовый протокол;
- никаких служебных разделов и меню судьи.

Скрытые и архивные соревнования публичной страницы не имеют (отвечают 404).

**Страница «Ссылки»** — «Соревнование» → «🔗 Ссылки». Собирает все публичные адреса:
хаб, саморегистрация, список зарегистрированных, результаты, табло, приложение,
а также таблицу стартов с публичными протоколами. Каждый адрес можно скопировать кнопкой.
Для старта можно создать **короткую ссылку** (`/sl/<токен>`) и перегенерировать её —
старая после этого перестаёт работать.

## 12. Мобильное приложение (Android)

Страница **«Соревнование» → «📱 Приложение Android»** (`/app`).

- Скачайте APK и установите (Android разрешит установку из неизвестного источника — это нормально).

- Внутри приложения нет меню и переходов на другие разделы: чтобы судья не ушёл с рабочего экрана.

## 13. Управление соревнованиями

Служебная страница **`/manage`**, отдельный пароль (по умолчанию `cedor` / `cedor`,
меняется переменными окружения на сервере).

Возможности:

- **создать соревнование** — новая пустая база; задаются название, логин и пароль администратора;
- **импорт соревнования** — создаётся из загруженного файла базы (`.db`), файл при загрузке не меняется;
- **переименовать** — название, которое видно **на странице входа** (в списке соревнований).
  Название внутри соревнования (в шапке, в протоколе) меняется отдельно — в его настройках;
  если они различаются, в карточке управления показано «в приложении: …»;
- **скопировать** — новое соревнование из существующего с выбором, что очистить:
  участники, старты и заезды, категории (вместе со стартами), настройки саморегистрации,
  журнал заявок, данные протокола. Пользователи и пароли копируются всегда;
- **экспорт БД** — скачать файл базы соревнования;
- **архив** — соревнование видно в управлении, но не на странице входа;
  прямая ссылка `/c/<код>` продолжает работать;
- **скрыть** — то же, но помечается отдельно: не видно на странице входа, доступно только по ссылке;
- **удалить** — стирает соревнование и файл базы без резервной копии (необратимо);
- **включить/выключить «только чтение»** — включается только если нет незавершённых стартов;
- **сменить логин и пароль пользователя** — выбрать пользователя, при необходимости задать новый
  логин (2–40 символов) и/или новый пароль (минимум 4 символа); пустое поле не меняется.
  Выручает, если судья забыл пароль или хочет сменить логин;
- **обновить список участников для подстановки** — общий список с bike.cedor.ru, используется
  во всех соревнованиях для подсказок при вводе ФИО (обновляется автоматически раз в сутки).

### Доступ к самой странице управления

Внизу страницы — блок **«Доступ к управлению»**: логин и пароль, под которыми открывается `/manage`
(это отдельная учётная запись, не связанная с логинами соревнований).

- Чтобы изменить — введите **текущий пароль** и укажите новый логин и/или новый пароль
  (пустое поле не меняется).
- Пароль хранится в виде хэша (scrypt) в файле `manage.json` каталога данных.
- Пока файла нет, действуют значения из переменных окружения сервера
  (`CHRONO_MANAGE_USER` / `CHRONO_MANAGE_PASS`, по умолчанию `cedor` / `cedor`).
- Чтобы вернуться к учётке из переменных окружения — удалите `manage.json`.

### Как устроена страница

- Сверху — карточка **«Соревнование»** с вкладками: **＋ Новая база** и **📥 Из файла БД**.
- Ниже — **фильтры-счётчики**: Все · Активные · В архиве · Скрытые · Только чтение ·
  С незавершёнными. Клик по чипу оставляет в списке только подходящие соревнования.
- Каждое соревнование — карточка: название, ссылка `/c/…` с кнопкой **⧉** (скопировать ссылку),
  дата создания, количество участников, стартов и размер базы.
- **Переименование — прямо в карточке**: нажать ✏️ (или дважды кликнуть по названию),
  ввести новое имя, сохранить кнопкой ✓ (Esc — отмена). Меняется только название
  на странице входа; название внутри соревнования остаётся прежним.
- **Переключатели** под карточкой: «Архив», «Скрыто», «Только чтение» — одно касание
  меняет состояние.
- Остальные действия — в меню **«⋮»**: открыть, сменить пароль, копировать, экспорт БД, удалить.
- Архивные соревнования — в отдельной сворачивающейся секции **«Архив»** внизу списка.
- **Удаление** требует ввести название соревнования в поле подтверждения — случайно не нажмётся.

Перед удалением стоит сделать **«Экспорт БД»** — потом соревнование можно вернуть через «Импорт».

### Архив и «скрытое»

Оба флага убирают соревнование со страницы входа, но не мешают работе по прямой ссылке.

- **Архив** — прошедшие соревнования, которые не должны попадаться на глаза.
- **Скрытое** — соревнование в работе, но его не должно быть в общем списке
  (например, тестовое или закрытое для участников).

Пока в соревновании есть незавершённые старты, архивировать и скрывать его нельзя —
иначе оно пропадёт со страницы входа прямо во время гонки. Сначала завершите старты.

### Режим «только чтение»

Данные можно смотреть, но нельзя менять: любые действия блокируются, в шапке — жёлтая полоса.
Удобно для прошедших соревнований.

## 14. Данные, резервные копии, обновление

- Данные каждого соревнования — отдельный файл базы SQLite.
- Общий список участников для подстановки — отдельная база `people.db`.
- Всё лежит в каталоге данных на сервере (в Docker — том `/opt/chrono-data`):
  `chrono.db`, `competitions.json`, `comps/`, `people.db`, `backups/`, `log/`.
- Резервная копия — копия файла базы (лучше при остановленном приложении или через `sqlite3 .backup`).

Обновление приложения на сервере:

```bash
cd /opt/chrono
sudo docker compose up -d --build
```

Логи: `docker logs --tail=200 chrono-site`, файлы — в `/opt/chrono-data/log/`.

## 15. Частые вопросы

**Не вижу участника в стартах.**
Проверьте две вещи: у участника **выдан стартовый номер** («Соревнование» → «🔢 Выдать номера»)
и назначена категория. Участники без номера или «Без категории» в старты не попадают.

**Участнику не подобралась категория при саморегистрации.**
Скорее всего не включено поле «Пол» или «Год рождения», а категория с ограничением по этим данным.
Проверьте настройки саморегистрации — система предупредит об этом плашкой.

**Судья ввёл не тот номер.**
На странице «Хронометраж» нажмите «↶» — последняя отметка отменяется. Если отметка древнее —
удалите круг в карточке старта или поправьте финиш.

**Участник отстал на круг.**
В колонке «Круги» показывается «пройдено / по регламенту» (например 2 / 3) и пометка «+1 кр.».

**Не работает ссылка саморегистрации.**
Проверьте: включена ли регистрация, не прошла ли дата окончания, не включён ли режим «только чтение».

**Забыли пароль администратора соревнования.**
