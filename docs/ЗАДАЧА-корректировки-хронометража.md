# Задача: корректировки хронометража (тип старта, дата, возраст в категориях)

Статус: **реализовано** (24.11.2026). Уточнено и сделано.

Что сделано:
- тип старта задаётся при создании (`/manage`), на `/competitions` — только чтение;
  бейдж «Разделка» / «Массовый» на странице входа и в управлении;
- поле `start_date` в настройках соревнования, показывается в регистрации и списке
  зарегистрировавшихся; при смене года — вопрос о пересчёте категорий;
- в категориях строка возраста (`age_range`) + вычисляемые годы рождения
  (`year_from`/`year_to`) и подсказка «2016–2017 г.р.»; миграция старых годов в возраст;
- жёлтая подсветка участников, не попадающих в свою категорию (возраст + пол);
- тесты: `tests/test_ages.py`, `tests/test_format.py`.

## Решения (зафиксированы)

1. **Дата старта** — отдельное поле `start_date` (плановая дата старта соревнования),
   НЕ переиспользует `proto_date`/`proto_start_time`.
2. **Возраст в категориях** — в БД по-прежнему хранятся **года** (`year_from`/`year_to`),
   а для ввода хранится **строка пользователя в одном поле** `age_range` (например,
   `9-10`, `-6`, `9-`, `9`, пусто = любой возраст).
3. **Подсказка** — в категории выводить, какие годы рождения в неё попадают
   (текст: «2016–2017 г.р.»).
4. **Пересчёт при смене года** — пересчитывать **всех** участников.
5. **Участник без подходящей категории** после пересчёта — **оставить как есть**.
6. **Миграция** — если у соревнования нет даты старта, при миграции подставить
   **текущую дату**.
7. **Жёлтая подсветка** — учитывать **возраст и пол** (полное совпадение с условиями
   категории).
8. **Бейдж на главной** — текст «Разделка» / «Массовый».

- На главной (`/`) у карточки — бейдж «Разделка» / «Массовый».

## 3. Возраст в категориях (строка → годы)

- Добавить колонку `age_range TEXT` (сырая строка пользователя). `gender`,
  `year_from`, `year_to` — сохранить.
- `year_from`/`year_to` становятся **вычисляемыми** из `age_range` и года старта.
- Возраст = `год старта − год рождения` (на 31 декабря года старта).
- Окно годов: `age_range` → `[age_min, age_max]` (пустой край = NULL):
  - `9-10` → 9..10; `-6` → (−∞..6); `9-` → (9..+∞); `9` → 9..9; пусто → любой.
  - `year_from = start_year − age_max`, `year_to = start_year − age_min`
    (NULL там, где край не задан).
- В UI категории: ввод строки + текстовая подсказка годов
  («9–10 лет → 2016–2017 г.р.»).
- Пол категории — без изменений.

### Задачи
10. Схема: `ALTER TABLE categories ADD COLUMN age_range TEXT`.
11. Разбор строки → `age_min`/`age_max` (+ валидация: целые ≥ 0, `min ≤ max`).
12. `chrono/catalog.py`: функция `_apply_age_range(conn, cid, start_year)` —
    пересчёт `year_from`/`year_to` у всех категорий по их `age_range`.
13. Сохранение категории: хранить `age_range`, вычислять годы через
    `_apply_age_range`.
14. UI категорий: ввод возраста строкой + подсказка «г.р.».
15. Миграция существующих категорий: заполнить `age_range` из `year_from`/`year_to`,
    используя год `start_date` (или текущую дату, если пусто).
16. Тесты: парсинг `9-10`, `-6`, `9-`, `9`, пусто; вычисление окна годов;
    матчинг `_category_matches`; авто-категория.

## 4. Пересчёт категорий при смене года

- При сохранении `start_date`: если изменился **год** — показать подтверждение
  «Пересчитать категории участников?».
- Пересчёт = пересчитать `year_from`/`year_to` категорий (`_apply_age_range`) и
  переопределить `category_id` **всех** участников через `_auto_category`
  (пол + возраст).
- Участник без подходящей категории — **оставить текущий** `category_id`.

### Задачи
17. Сохранение `start_date` с детектом смены года → подтверждение → пересчёт.
18. Пересчёт всех участников (пол + возраст); без совпадения — без изменений.
19. Тесты: смена года → пересчёт категорий и участников; сохранение при отсутствии
    совпадения.

## 5. Жёлтая подсветка «не целевой категории»

- В списке участников строка подсвечивается жёлтым, если участник **не попадает**
  в условия своей категории по **возрасту и полу** (полное `_category_matches`).
- Не ошибка — только визуальный индикатор.

### Задачи

21. Маршрут списка участников: пометка `mismatch = category and not _category_matches(...)`.
22. Тесты: участник вне диапазона/пола → подсветка; совпадающий — без.

## Риски

- **Миграция годов→возраст**: категории без даты старта — берём текущий год (по п. 6).
- **Пересчёт всех** перезаписывает ручные назначения категорий — это согласовано (п. 4).
- **`year_from`/`year_to` как вычисляемые**: при любом изменении `age_range` или года
  старта их надо пересчитывать одной функцией, чтобы не рассинхронизировались.
- Возраст без года рождения — не подходит под возрастные категории (не подсвечивать,
  не авто-назначать в возрастные).
