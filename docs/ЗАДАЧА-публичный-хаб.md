# Задача: публичный хаб соревнования и страница «Ссылки»

Статус: **реализовано** (23.11.2026), проверено локально и на hrono.cedor.ru.

## 1. Цель

Собрать все публичные адреса соревнования в одном месте:

- **публичный хаб** `/p/<slug>` — одна ссылка для участников и зрителей,
  с регистрацией, результатами, табло и стартовыми протоколами;
- **страница «Ссылки»** внутри соревнования — рабочее место судьи: все публичные
  адреса и управление короткими ссылками на старты.

## 2. Принятые решения

| Вопрос | Решение |
|---|---|
| Публичный хаб | **делаем**, `/p/<slug>` |
| Стартовые протоколы в хабе | **все старты соревнования**, без токенов |
| Короткие ссылки `/sl/<token>` | остаются как «прямая ссылка на старт» |
| QR-коды и печать | **не нужны** |
| Массовая генерация и отзыв ссылок | **не нужны** |
| История ссылок | **не нужна**, показывается текущее состояние |
| Кто видит страницу «Ссылки» | все, кто может войти в соревнование |
| Главная страница | у соревнования **две кнопки**: «Войти» и «Публичная страница» |
| Архивные соревнования | **хаба нет** (публичная кнопка скрыта, `/p/<slug>` → 404) |

## 3. Главная страница `/`

Сейчас: публичный список соревнований, у каждого одна кнопка «Войти» → `/c/<slug>`.

Стало:

- **«Войти»** — как сейчас (судьи; при отсутствии сессии ведёт на логин);
- **«🌐 Публичная страница»** — сразу на `/p/<slug>`, без входа;
- у **скрытых** соревнований карточки нет (как сейчас), значит нет и хаба;
- у **архивных** карточка есть, но публичной кнопки нет — только «Войти»
  (режим только для чтения).

## 4. Публичный хаб `/p/<slug>`

Без авторизации. Содержимое сверху вниз:

1. **Шапка**: название соревнования, дата (из первого старта) или «дата не задана».
2. **Кнопки**:
   - «Зарегистрироваться» → `/reg/<slug>` — только если саморегистрация включена;
   - «Результаты» → `/p/<slug>/results`;
   - «Табло» → `/p/<slug>/live`.
3. **Стартовые протоколы**: список всех стартов соревнования, по возрастанию номера:
   - старт №N · название (если есть) · статус (готов / идёт / завершён) · участников;
   - ссылка «протокол» → `/p/<slug>/sl/<hid>`.
4. Служебных ссылок (меню судьи, «Хронометраж», «Ссылки», управление) — нет.

Правила:

- соревнование **скрытое** → 404;
- соревнование **архивное** → 404 (ссылки на него с главной нет);
- неизвестный slug → 404;
- страница адаптивна под телефон, без авторизации и без сессии.

## 5. Публичные маршруты хаба

| Маршрут | Назначение | Правила |
|---|---|---|
| `/p/<slug>` | хаб | скрытое/архивное/неизвестное → 404 |
| `/p/<slug>/results` | публичные результаты этого соревнования | по умолчанию последний старт; только база этого соревнования |
| `/p/<slug>/live` | табло финиша этого соревнования | то же, что `/finish-screen`, но база выбирается по slug |
| `/p/<slug>/sl/<hid>` | стартовый протокол старта | старт должен принадлежать этому соревнованию, иначе 404 |
| `/p/<slug>/live/data` | автообновление табло (если используется AJAX) | только это соревнование |

Все они входят в `PUBLIC_ENDPOINTS`.

**Важно:** сейчас `/results` и `/finish-screen` берут базу «текущего» соревнования
из сессии, а у анонимного посетителя — базу по умолчанию. Поэтому логику рендера
результатов и табло нужно вынести в функции, принимающие базу/соревнование, и вызвать
их из публичных маршрутов с нужным slug.

## 6. Страница «Ссылки» (внутри соревнования)

Раздел **«Соревнование» → «🔗 Ссылки»**, доступна всем, кто вошёл в соревнование.
Ссылка на раздел — в меню/на странице соревнования.

Блок 1 — **постоянные ссылки** (карточки или строки): адрес, «Копировать», «Открыть».

| Ссылка | Условие показа |
|---|---|
| Хаб `/p/<slug>` | соревнование не архивное |
| Саморегистрация `/reg/<slug>` | саморегистрация включена |
| Список зарегистрированных `/reg/<slug>/list` | саморегистрация включена |
| Результаты `/p/<slug>/results` | всегда |
| Табло `/p/<slug>/live` | всегда |
| Приложение `/app` | всегда |

Блок 2 — **стартовые протоколы**: таблица стартов.

| Колонка | Содержимое |
|---|---|
| Старт | № и название |
| Статус | готов / идёт / завершён |
| Участников | количество |
| Публичный протокол | ссылка `/p/<slug>/sl/<hid>` + «Копировать» |
| Короткая ссылка | токен `/sl/<token>`: «создать» / готовый адрес + «копировать» / «перегенерировать» |

Действия:

- «создать короткую ссылку» — генерирует токен (как сейчас в протоколе);
- «перегенерировать» — с подтверждением «старая ссылка перестанет работать»;
- у архивного соревнования блок хаба показывает «публичная страница недоступна
  для архивного соревнования», остальные строки остаются.

Чего на странице **нет**: QR-кодов, печати, массовой генерации, массового отзыва,
истории изменений.

## 7. Детали реализации

1. **Выбор базы по slug**: helper, который по записи реестра открывает нужную базу
   и отдаёт `(conn, competition)`, с закрытием соединения в `finally`.
2. **Проверка доступности хаба**: `hidden` → 404, `archived` → 404.
3. **Рефакторинг результатов**: выделить отрисовку страницы результатов в функцию
   от `(conn, cid, target, include_auto)`, чтобы использовать её и в приватном,
   и в публичном маршруте.
4. **Рефакторинг табло**: то же для `/finish-screen` и `/finish-screen/data`.
5. **Стартовый протокол по hid**: проверить, что `heats.competition_id` совпадает
   с соревнованием slug, иначе 404; рендер — существующий `startlist_public.html`.
6. **Главная**: в карточке соревнования добавить вторую кнопку, скрывать её
   для архивных.
7. **Меню**: пункт «Ссылки» рядом с «Саморегистрацией»/«Категориями».
8. **Копирование**: `navigator.clipboard` + запасной вариант «выделить текст»,
   короткий тост «скопировано».
9. **Кэширование**: не кэшировать публичные страницы (заголовок `Cache-Control: no-store`),
   чтобы протоколы и результаты были свежими.

## 8. Тесты

Публичные маршруты:

- `/p/<slug>` — 200 для активного соревнования; 404 для скрытого, архивного и несуществующего;
- в хабе есть кнопки «Результаты» и «Табло», список всех стартов со статусами и числом участников;
- «Зарегистрироваться» есть при включённой саморегистрации и отсутствует при выключенной;
- `/p/<slug>/results` показывает результаты **только этого** соревнования (проверить на двух соревнованиях);
- `/p/<slug>/live` и `/p/<slug>/live/data` — 200, показывают старт этого соревнования;
- `/p/<slug>/sl/<hid>` — 200; чужой `hid` → 404; скрытое/архивное → 404;
- без логина все перечисленные страницы открываются, служебных ссылок в разметке нет.

Страница «Ссылки»:

- доступна любому вошедшему в соревнование;
- показывает хаб, регистрацию (если включена), результаты, табло, приложение;
- для каждого старта — публичная ссылка на протокол;
- «создать короткую ссылку» возвращает токен, «перегенерировать» меняет его,
  старая ссылка перестаёт открываться (404);
- у архивного соревнования строка хаба помечена как недоступная.

Главная:

- у активного соревнования две кнопки, публичная ведёт на `/p/<slug>`;
- у архивного — только «Войти»;
- скрытое соревнование в списке отсутствует.

Регресс: судейские страницы, результаты, табло, стартовые протоколы, регистрация.
